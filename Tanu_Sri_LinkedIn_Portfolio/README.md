# Tanu Sri. R - LinkedIn Portfolio

A responsive single-page portfolio for Tanu Sri. R, B.Tech Artificial Intelligence and Data Science student.

## Files
- `index.html` - portfolio content
- `style.css` - responsive futuristic UI
- `script.js` - mobile navigation and scroll animations

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Before publishing
1. Replace the `TS` profile placeholder with your professional photo if desired.
2. Add your email address to the Contact section.
3. Add your final resume PDF and a Resume button if needed.
4. Verify project descriptions and GitHub links.
5. Deploy with GitHub Pages, Netlify, or Vercel.

## Important
This portfolio intentionally avoids inventing internship/company experience or certifications. Add only experiences and credentials you actually have.
